# M3 — 导出与集成

## 范围与语义

- 新组卷页增加默认不勾选的「附带解析」。参数经 DVA model 传入 `/questionGen2`。
- `/questionGen2` 与 `/reExportTestPaper` 共用 PaperExportContent 生成内容，再由 POI WordExport 导出。
- `withAnalysis` 省略或 false 时保留既有正文、题序、分数和模板格式；true 时每道有解析题目的题干下方显示「解析：……」。
- 解析为 null、空串或空白时仅省略解析段，保留题干。支持中文、CR/LF 多行、XML 特殊字符。
- 历史页增加重新导出试卷的勾选项。沿用现有“读取当前题库”的语义，不是出卷时的快照；当前题库删除的题目仍沿用原行为跳过。
- `/exportAnswer` 行为不变；导出不触发 AI API，不改变 M2 的解析生成与入库逻辑。
- 旧 `/questionGen` → GenWord → FreeMarker 模板也支持同名开关，并保持旧三参数调用兼容。新增路径正确转义 XML 文本。
- 前端下载先检查响应状态、Content-Type 与空文件，错误 JSON/text 不再被保存为 DOCX；等待下载处理完成后才提示成功。
- 无数据库迁移；不改遗传、贪心算法及既有 Mapper SQL。

## 基线构建修复（与 M2 对接注意）

本次完整构建发现并修复两项前端基线问题：
1. `AiAnalysisModal.js` 中 utils/services 导入多退了一层目录，修正两行相对路径；未改 AI 弹窗业务逻辑。
2. Jest 的间接语法预设升级后要求比 Umi 3 所带 Babel 更高的版本。显式固定开发依赖 `babel-preset-current-node-syntax` 为 `1.0.1`，恢复现有 Jest/Babel 组合兼容。

M2 成员合并时注意这两行导入路径，其余 AI 模块未改动。未引入运行时新依赖或密钥。
