# 产品需求

本文档定义 TestPaperGen 的产品需求，是功能验收的基准。

## 1. 产品定位

在线组卷系统，服务高校教师与培训机构的日常出卷场景：管理题库、快速组卷、导出规范排版的 Word 试卷，并通过大模型自动生成试题解析，减少教师手动编写解析的重复劳动。

## 2. 用户角色

| 角色 | 描述 |
|---|---|
| 普通教师 | 核心用户。编制课堂练习、作业与考试试卷，维护个人题库，执行组卷与导出 |
| 系统管理员 | 管理系统账号，维护基础运行环境，保障题库与试卷数据可用 |

## 3. 功能规格

### 3.1 教师端

| 编号 | 功能 | 规格说明 |
|---|---|---|
| F-01 | 账号注册登录 | 账号密码注册与登录；未登录状态禁止访问业务功能；登录后可维护题库并组卷 |
| F-02 | 题库管理 | 支持选择题、判断题、填空题、阅读题、设计题的新增、修改、删除、查询；支持上传 Excel 批量导入；题目信息包含题干、答案、解析 |
| F-03 | AI 生成试题解析 | 选中题库题目一键生成解析；解析保存至数据库；导出试卷时可选择是否附带解析 |
| F-04 | 手动组卷 | 浏览题库，勾选题目加入试卷，完成手动组卷 |
| F-05 | 自动算法组卷 | 按章节、难度、题型数量、总分等条件，基于遗传算法与贪心算法自动组卷；支持生成多套 A/B 平行试卷 |
| F-06 | 试卷导出与历史 | 导出 Word 试卷与参考答案；保存出卷历史；支持查看历史试卷并二次编辑 |
| F-07 | 数据可视化 | 通过 ECharts 图表查看题库与试卷的题型、难度分布统计 |

### 3.2 管理员端

| 编号 | 功能 | 规格说明 |
|---|---|---|
| F-08 | 账号管理 | 查看全部注册账号，进行基础管理维护 |
| F-09 | 系统基础维护 | 查看系统基础运行状态，保障题库、试卷数据正常可用 |

## 4. 需求验收基准

| 需求 ID | 需求描述 | 类型 | 优先级 |
|---|---|---|---|
| R-01 | 教师可以注册、登录系统，未登录拦截业务访问 | 功能 | P0 |
| R-02 | 题库支持多题型增删改查，支持 Excel 批量导入试题 | 功能 | P0 |
| R-03 | 支持手动组卷；基于遗传、贪心算法实现自动组卷，可生成 A/B 卷 | 功能 | P0 |
| R-04 | 组卷后导出 Word 试卷与参考答案；保存出卷历史，支持历史试卷二次编辑 | 功能 | P0 |
| R-05 | ECharts 实现题库、试卷统计可视化展示 | 功能 | P0 |
| R-06 | AI 一键生成试题解析，解析存入数据库，导出试卷可选附带解析 | 功能 | P0 |
| R-07 | 管理员账号管理功能 | 功能 | P1 |
| R-08 | 普通接口响应小于 1 秒；AI 接口 15 秒超时 | 非功能 | P0 |
| R-09 | 接口鉴权、密钥安全存储、用户数据隔离 | 非功能 | P0 |
| R-10 | 界面操作简单友好，导出文档格式兼容 Office/WPS | 非功能 | P0 |

## 5. 非功能规格

| 类别 | 指标 |
|---|---|
| 性能 | 普通增删改查接口响应 < 1s；自动组卷算法执行 < 10s；AI 生成解析接口超时 15s，超时返回友好提示 |
| 安全 | 基于拦截器的登录鉴权；大模型 API 密钥仅存放于后端配置，前端不暴露；不同用户数据逻辑隔离；输入数据合法性校验 |
| 易用性 | Web 界面简洁直观；错误提示使用自然语言，不展示后端异常；导出 Word 排版规整，兼容 Office / WPS |
| 可扩展 | AI 解析模块与组卷模块低耦合，不修改组卷算法核心逻辑；预留 PDF 导出、试题标签扩展空间 |

## 6. 技术选型

后端 Java Spring Boot；前端 React + Umi；数据库 MySQL；组卷算法遗传 + 贪心；AI 调用第三方大模型 API（OpenAI 兼容协议）；可视化 ECharts；文档导出 Apache POI 生成 Word。
