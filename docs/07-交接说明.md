# 开发指南

面向新加入的开发者：从零跑通项目，并快速定位代码与排查问题。

## 1. 环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 8+ | 高版本 JDK 需确认 Maven 编译器级别兼容 |
| Maven | 3.6+ | 依赖下载慢可配阿里云镜像 |
| Node.js | 14+（建议 16） | 前端 Umi 3 时代 |
| MySQL | 5.7+ / 8.0 | 字符集 utf8mb4 |

## 2. 数据库初始化

```bash
mysql -u root -p < database/base/test_paper_generation_base.sql
mysql -u root -p < database/migrations/001_ai_analysis.sql
```

base 脚本自带约 1300 条题库样例数据，可直接体验组卷。增量脚本可重复执行（幂等）。

## 3. 后端启动

```bash
cd TestPapaerGen-Backend
mvn install
mvn package
java -jar target/test-paper-generation-3.0.0.jar
```

- 默认端口 **80**（`server.port`），被占用时改 `application.yml`；
- 数据库账号密码：`DB_USERNAME`（默认 root）/ `DB_PASSWORD`（默认 root，环境变量覆盖）；
- AI 密钥：`AI_API_KEY`，不配则 `ai.enabled=false` 走 Mock 模式；
- 也可在 IDEA 中直接运行 `TestPaperGenerationApplication`。

## 4. 前端启动

```bash
cd TestPapaerGen-Frontend
npm install
npm start        # 开发服务器 8000 端口
npm run build    # 构建产物在 dist/
```

- `.umirc.ts` 中 `publicPath: "/static/"`；本地开发请求基地址见 `src/config/requestConfig.js`（把后端端口从 8000 映射到 8081）；
- `history.type: 'hash'`，路由刷新不会 404。

## 5. 目录速查

| 想找什么 | 去哪 |
|---|---|
| AI 模块全部代码 | `TestPapaerGen-Backend/src/main/java/com/teemo/testpapergeneration/ai/` |
| 题库/组卷接口 | `controller/QuestionBankController.java`、`controller/QuestionGenController.java` |
| 组卷算法 | `services/GeneticIteration.java`（遗传）、`services/RandomSelectTopic.java`（贪心） |
| Word 导出 | `services/GenWord.java`、`services/WordExport.java`、`resources/res/*.ftl`、`resources/templates/*.docx` |
| 登录鉴权 | `config/LoginInterceptorConfig.java`、`component/LoginHandlerInterceptor.java` |
| 题库页 AI 入口 | `TestPapaerGen-Frontend/src/pages/questionBank/index.js` 操作列「解析」按钮 |
| 请求函数 | `src/services/requestServices.js`（按业务分段，AI 在文件末尾） |

## 6. 故障排查

| 现象 | 原因与处理 |
|---|---|
| 接口全部 403 | 未登录。拦截器只放行登录/注册/静态资源，`/aiAnalysis/**` 需要登录态，属预期 |
| 数据库连接失败 | 确认库名 `test_paper_generation` 已导入、`DB_PASSWORD` 已设置；时区看 url 中 `serverTimezone=Asia/Shanghai` |
| AI 生成提示"接口未配置 apiKey" | `ai.enabled=true` 但未配 `AI_API_KEY`：二选一，配密钥或把 enabled 改回 false 用 Mock 模式 |
| AI 生成慢/超时 | `ai.timeout-ms=15000` 是约束值；国内访问 OpenAI 官方接口不稳定时，换 `ai.base-url` 为国内可达的 OpenAI 兼容网关 |
| 前端改了没生效 | Umi 的 mfsu 缓存问题，删 `node_modules/.cache` 后重启 `npm start` |
| 端口 80 被占用 | Windows 常见于 IIS/其他服务：改 `server.port`，同步改前端 `requestConfig.js` 端口映射 |
| session 丢失需重新登录 | 后端重启即失效，属正常现象 |

## 7. Git 协作规范

- `main` 保持可编译、可启动；功能开发走 `feature/*` 分支，通过 PR 合并；
- Commit message 格式：`<模块>: <做了什么>`，如 `ai: 新增批量生成接口`；
- 禁止提交：数据库密码、AI API Key、`application-local.yml` 等本地配置（根 `.gitignore` 已屏蔽 `.workbuddy/`、`target/`、`node_modules/` 等）；
- 数据库变更必须新增 `database/migrations/` 编号脚本（幂等 + 回滚说明），不要直接改 base 脚本。
