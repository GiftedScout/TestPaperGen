# 07 - 交接说明

> 面向新加入的开发组员：从零开始把项目跑起来，并避开已知的坑。

## 1. 环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 8+（pom 固定 8） | 高版本 JDK 需确认 Maven 编译器级别兼容 |
| Maven | 3.6+ | 依赖国内下载慢可配阿里云镜像 |
| Node.js | 14+（建议 16） | 前端 Umi 3 时代 |
| MySQL | 5.7+ / 8.0 | 字符集 utf8mb4 |

## 2. 数据库初始化

```bash
# 全新安装
mysql -u root -p < database/base/test_paper_generation_base.sql
mysql -u root -p < database/migrations/001_ai_analysis.sql
```

base 脚本自带约 1300 条微机原理题库样例数据，可直接体验组卷。

## 3. 后端启动

```bash
cd TestPapaerGen-Backend
mvn install
mvn package
java -jar target/test-paper-generation-3.0.0.jar
```

- 默认端口 **80**（server.port），被占用时改 application.yml；
- 数据库账号密码：`DB_USERNAME`（默认 root）/ `DB_PASSWORD`（默认 root，环境变量覆盖）；
- AI 密钥：`AI_API_KEY`，不配则 `ai.enabled=false` 走 Mock 模式；
- 打包/调试都可在 IDEA 中直接运行 `TestPaperGenerationApplication`。

## 4. 前端启动

```bash
cd TestPapaerGen-Frontend
npm install
npm start        # 开发服务器 8000 端口
npm run build    # 构建产物在 dist/，由后端 static 目录托管时可自行放置
```

- `.umirc.ts` 中 `publicPath: "/static/"`，请求基地址见 `src/config/requestConfig.js`（本地开发把后端端口从 8000 映射到 8081）；
- `history.type: 'hash'`，路由刷新不会 404。

## 6. 常见问题（踩坑记录）

1. **接口全部 403**：未登录。拦截器排除名单只放行登录/注册/静态资源，`/aiAnalysis/**` 需要登录态，属预期。
2. **数据库连接失败**：确认库名 `test_paper_generation` 已导入、`DB_PASSWORD` 已设置；时区问题看 url 里的 `serverTimezone=Asia/Shanghai`。
3. **AI 生成返回"接口未配置 apiKey"**：`ai.enabled=true` 但没配 `AI_API_KEY`。二选一：配上密钥，或把 enabled 改回 false 用 Mock 模式。
4. **AI 生成慢/超时**：`ai.timeout-ms=15000` 是需求约束；国内访问 OpenAI 官方接口不稳定时，换 `ai.base-url` 为国内可达的 OpenAI 兼容网关（DeepSeek/Moonshot/OneAPI 等）。
5. **前端改了没生效**：umi 的 mfsu 缓存问题，删 `node_modules/.cache` 后重启 `npm start`。
6. **端口 80 被占用**（Windows 常见于 IIS/其他服务）：改 `server.port`，同步改前端 `requestConfig.js` 中的端口映射。
7. **session 丢失**：后端重启即失效，需重新登录，属正常现象。

## 7. Git 协作规范

- 主分支 `main` 保持可编译、可启动；功能开发走 `feature/xxx` 分支，完成后 PR 合并；
- Commit message 建议格式：`<模块>: <做了什么>`，如 `ai: 新增批量生成接口`、`docs: 补充交接说明`；
- **严禁提交**：数据库密码、AI API Key、`application-local.yml` 等本地配置（根 `.gitignore` 已屏蔽 `.workbuddy/`、`target/`、`node_modules/` 等）；
- 数据库变更必须走 `database/migrations/` 新增编号脚本，不要直接改 base 脚本。

- 需求问题：对照 `docs/01-需求摘要.md`，以需求规格表 10 条为验收基准；
- AI 模块行为：对照 `docs/03-AI解析模块.md` 容错表；
- 接口行为：对照 `docs/05-接口文档.md`。
