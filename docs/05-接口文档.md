# 05 - 接口文档

## 1. 通用约定

- 响应体统一：`{ "code": 200, "msg": "请求成功", "data": <业务数据> }`；`code=500` 时 `msg` 为友好提示；
- 鉴权：除登录/注册/静态资源外，所有业务接口（含全部 `/aiAnalysis/**`）经过 `LoginHandlerInterceptor`，未登录返回 403；
- 前端请求统一经 `services/requestServices.js`，`checkCode(res)` 判断 `code===200`。

## 2. AI 解析模块接口（二次开发新增）

### 2.1 生成并保存单题解析

```
POST /aiAnalysis/generate
Content-Type: application/json

{ "questionId": 1184 }
```

成功（code=200）：

```json
{
  "code": 200,
  "msg": "请求成功",
  "data": {
    "id": 1184,
    "topic": "若机器字长为16位……",
    "topic_type": "填空题",
    "answer": "0~65535",
    "analysis": "本题考查无符号数的表示范围……",
    "analysis_status": 1,
    "analysis_update_time": "2026-10-12 23:10:00"
  }
}
```

失败（code=500）：`{"code":500,"msg":"大模型接口调用失败（网络异常或超时）：…","data":"request parameter error, log time:…"}`

### 2.2 批量生成解析

```
POST /aiAnalysis/batchGenerate
{ "questionIds": [1184, 1186, 1187] }
```

响应 `data` 为逐题结果数组，单题失败不影响其他题：

```json
{
  "code": 200,
  "data": [
    { "questionId": 1184, "success": true,  "analysis": "……" },
    { "questionId": 1186, "success": false, "error": "题目不存在，id=1186" }
  ]
}
```

### 2.3 查询单题解析

```
GET /aiAnalysis/{id}
```

响应 `data` 为完整 QuestionBank（含 analysis 字段）。

### 2.4 手动修改解析

```
PUT /aiAnalysis/{id}
Content-Type: application/json

{ "analysis": "教师手动编辑后的解析内容" }
```

响应 `data`：`{ "updateStatus": 1 }`。失败：内容为空返回 `解析内容不能为空`；超长返回 `解析内容超长（上限 2000 字符）`。

### 2.5 查询模块状态（脱敏）

```
GET /aiAnalysis/status
```

响应：

```json
{ "code": 200, "data": { "enabled": false, "provider": "openai-compatible", "model": "gpt-3.5-turbo", "timeoutMs": 15000 } }
```

不含 apiKey。前端可据此提示"AI 未启用，当前为演示模式"。
