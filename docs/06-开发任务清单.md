# 路线图与任务清单

## 1. 迭代原则

每轮可独立编译、可演示、可验收；AI 模块与组卷功能严格分离，任何一轮不影响系统主流程。

## 2. 当前版本（v0.3）

AI 解析主链路与管理员配置已可用：

- AI 模块 6 个类，**8 个 HTTP 接口**：generate / batchGenerate / {id} GET / {id} PUT / status / config / test / models
- 单题解析：生成、查看、人工编辑全链路可用（Mock 模式可无密钥演示）
- 批量解析：题库页多选 + 逐题结果弹窗，解析状态列可筛选
- 管理员配置页 `/aiConfig`：改地址/模型/Key、拉取模型列表、连通性测试，保存即时生效
- 后端测试 23 项全绿（含 AI 配置与导出链路）
- 数据库增量脚本已合入
- 开发文档与规范齐备

验收标准：真实密钥下生成 10 题解析全部成功且内容合理；批量生成中故意混入 1 个不存在的 id，其余题目正常生成；断网或错误密钥时前端展示友好提示，系统其他功能正常。

实测补充（2026-11-18）：真实网关下 4 题生成成功并落库（208–395 字符）；错误 Key 返回「API Key 无效或未授权（HTTP 401）」并展示在解析弹窗内；批量中混入非法 id 时逐题隔离正常。第三方网关存在偶发空返回与输出截断，客户端已加 3 次重试。

## 4. 已知限制与风险

| # | 事项 | 影响 | 建议 |
|---|---|---|---|
| 1 | 批量生成为顺序执行，耗时 ≈ 题数 × 单次耗时 | 大批量场景体验差 | 评估加并发上限（如 3 并发）或进度提示 |
| 2 | 历史重导出读取当前题库，无解析快照 | 题库后续修改会影响重导出；删除题目会跳过该题 | 如需历史快照，另立迁移与持久化任务 |
| 3 | 解析与题目同表，题目删除时解析一并删除 | 数据一致性符合预期 | 无需处理，仅登记 |
| 4 | **题库答案大量为占位符 `AAAA`**（589 题中 587 题） | 任何基于答案的自动判题都不可信 | 已在 [docs/10](10-任务包A-学生端与判题报告.md) 立项 A0 答案治理 |
| 5 | 运行时 AI 配置不持久化 | 重启丢失 Key，需重配 | 已立项 B3：磁盘加密存储 |
| 6 | CORS 为 `allowedOrigin("*") + allowCredentials(true)` | 任意站点可带 Cookie 调接口，属安全债 | B4 改为可配置白名单 |
| 7 | 上游基线代码未附带开源许可证 | 本项目整体以 Apache 2.0 发布，基线部分权利归原作者 | 权利声明见 [NOTICE](../NOTICE)，仅作学习用途 |

> 已解决：本地已具备 JDK 8 + Maven 离线依赖 + 便携 MySQL，`mvn test`（23 项）与 `mvn package` 可直接执行，不再存在"Java 改动未经编译验证"的问题。
