# 路线图与任务清单

## 1. 迭代原则

每轮可独立编译、可演示、可验收；AI 模块与组卷功能严格分离，任何一轮不影响系统主流程。

## 2. 当前版本（v0.2）

框架已就绪，AI 解析主链路可用：

- AI 模块 6 个类，5 个 HTTP 接口全部可用
- 单题解析：生成、查看、人工编辑全链路可用（Mock 模式下可无密钥演示）
- 数据库增量脚本已合入
- 开发文档与规范齐备

## 3. 迭代计划

### M2 — AI 解析功能完善

- [ ] 配置真实大模型密钥，验证 `ai.enabled=true` 全流程（建议选用国内可达的 OpenAI 兼容网关降低延迟）
- [ ] 题库页表格展示解析状态列（有/无解析），支持按有无解析筛选
- [ ] 批量生成前端入口：题库页多选题目 → 批量生成（调用已就绪的 `/aiAnalysis/batchGenerate`），展示逐题结果
- [ ] 提示词模板按实际题库调优，调优结论记录到 [docs/03](03-AI解析模块.md) 第 3 节
- [ ] 补充后端单元测试：AiAnalysisService 校验分支（空返回/超长/题目不存在）

验收标准：真实密钥下生成 10 题解析全部成功且内容合理；批量生成中故意混入 1 个不存在的 id，其余题目正常生成；断网或错误密钥时前端展示友好提示，系统其他功能正常。

### M3 — 导出与集成

- [ ] `/questionGen2` 读取 `withAnalysis` 参数，透传至 GenWord
- [ ] GenWord/WordExport 模板填充支持附带解析（FreeMarker 模板 `.ftl` 增加解析段落，注意转义）
- [ ] 前端组卷页导出区增加「附带解析」勾选，`questionGen2` payload 传 `withAnalysis`
- [ ] 历史试卷重新导出（reExportTestPaper）同步支持附带解析

验收标准：勾选附带解析导出的 Word 中，每题下方出现解析段落；不勾选时与既有导出效果完全一致（diff 对比）。

### M4 — 管理员与收尾（P1）

- [ ] 管理员账号管理功能完善（对应需求 R-07）
- [ ] 性能验证：普通接口 < 1s；组卷 < 10s；AI 接口 15s 超时行为验证
- [ ] 安全复查：git 历史无密钥/密码明文；`/aiAnalysis/status` 脱敏有效
- [ ] 易用性走查：错误提示均为自然语言；导出文档 Office/WPS 打开正常

## 4. 已知限制与风险

| # | 事项 | 影响 | 建议 |
|---|---|---|---|
| 1 | 批量生成为顺序执行，耗时 ≈ 题数 × 单次耗时 | 大批量场景体验差 | M2 评估加并发上限（如 3 并发）或进度提示 |
| 2 | `withAnalysis` 参数仅预留未实现 | M3 前导出不带解析 | 按 M3 迭代 |
| 3 | 解析与题目同表，题目删除时解析一并删除 | 数据一致性符合预期 | 无需处理，仅登记 |
| 4 | 本机无 JDK/Maven 时 Java 改动未经编译验证 | 合并前需在实际环境验证 | 合入 feature 分支前执行 `mvn package` |
| 5 | 上游基线代码未附带开源许可证 | 本项目整体以 Apache 2.0 发布，基线部分权利归原作者 | 权利声明见 [NOTICE](../NOTICE)，仅作学习用途 |
