# 06 - 开发任务清单

> 迭代原则：每轮可独立编译、可演示、可验收；AI 模块与上游功能严格分离，任何一轮不影响系统主流程。

## M1 — 框架搭建（已完成）

- [x] 上游代码纳入仓库，目录/包名保持不变
- [x] AI 模块骨架：AiConfig / AiClient / OpenAiCompatibleClient / AiAnalysisService / AiAnalysisController / AiException
- [x] QuestionBank 实体 + Mapper 扩展（3 字段 + updateAnalysisById）
- [x] 数据库增量脚本 `database/migrations/001_ai_analysis.sql`
- [x] 前端：请求函数、AiAnalysisModal、题库页「解析」入口
- [x] Mock 模式：`ai.enabled=false` 全链路可演示
- [x] 交接文档（docs/ 全部）

**验收标准**：`mvn package` 通过；执行 migration 后 `SHOW COLUMNS` 见 3 个新字段；前端题库页每题操作列出现「解析」按钮，点击弹出弹窗，Mock 模式下可生成占位解析并入库。

## M2 — AI 解析功能完善

- [ ] 配置真实大模型密钥，验证 `ai.enabled=true` 全流程（建议用 DeepSeek 等国内可达网关降低延迟）
- [ ] 题库页表格展示解析状态列（有/无解析），支持按有无解析筛选
- [ ] 批量生成前端入口：题库页多选题目 → 批量生成（调用已就绪的 `/aiAnalysis/batchGenerate`），展示逐题结果
- [ ] 提示词模板按实际题库调优（改 `ai.prompt-template`，记录调优结论到本文档）
- [ ] 补充后端单元测试：AiAnalysisService 校验分支（空返回/超长/题目不存在）

**验收标准**：真实密钥下生成 10 题解析全部成功且内容合理；批量生成中故意混入 1 个不存在的 id，其余题目正常生成；断网/错误密钥时前端展示友好提示，系统其他功能正常。

## M3 — 导出与集成

- [ ] `/questionGen2` 读取 `withAnalysis` 参数，透传至 GenWord
- [ ] GenWord/WordExport 模板填充支持附带解析（freemarker 模板 `.ftl` 需增加解析段落，注意转义）
- [ ] 前端组卷页导出区增加「附带解析」勾选，`questionGen2` payload 传 `withAnalysis`
- [ ] 历史试卷（reExportTestPaper）同步支持附带解析

**验收标准**：勾选附带解析导出的 Word 中，每题下方出现解析段落；不勾选时与上游导出效果完全一致（diff 对比）。
